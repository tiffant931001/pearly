# Pearly v10 更新說明

## 這版改了什麼

| 項目 | 內容 |
|---|---|
| 新角色 | 首頁換成新角色。打開時先顯示靜態圖，會動的角色在背景載入（`char10.js`），音效在第一次點畫面後才載入（`snd10.js`） |
| 長按付款 | 新魔法：集氣 → 炸成愛心 → 飛出去；背景變粉色的格子保留。付款按鈕放開後約 1.2 秒跳到 LINE Pay |
| GitHub 自動同步 | 捷徑把付款資料存到私人倉庫 `pearly-inbox`，打開 Pearly 自動收進來，不用按貼上 |
| 待確認規則 | 所有來源（同步、貼上、Apple Pay）都先進待確認，不再自動記帳；猜到的分類會用粉紅框標出來，點一下就存入 |
| 心情狀態 | 角色左上顯示心情（開心／有點擔心／慌張／睡覺中），右下顯示「連續 N 天」；心情改變後第一次打開，右上會出現 MOOD 泡泡 4 秒 |
| 同步失敗提示 | 同步失敗時，首頁待確認區會出現「上次同步失敗」，點進去是設定頁；下次成功就消失 |
| 新解析 | 讀得懂 LINE 錢包通知、中信 Home Bank 刷卡通知、中信 LINE 卡片、中信簡訊；簡訊裡的驗證碼不會保存 |

資料 key 沒有改（`pearly-app-v1`），**原本的記帳資料會保留**。

## 角色動畫的時機

**打開 App 時**（離開超過 5 分鐘再回來才算；同時符合時只播最上面那一個）

| 狀況 | 角色 |
|---|---|
| 21:00～06:00 | 戴睡帽睡覺，背景淡紫 |
| 總預算已超支 | 超支很嚴重的動畫，播完是普通臉 |
| 總預算剩不到 15% | 小的內疚動畫，播完是普通臉 |
| 有還沒看過的同步記錄 | 記帳開心 |
| 以上都沒有 | 揮手打招呼 |

**其他時候**

| 觸發 | 角色 |
|---|---|
| 點角色 1～4 下 | 每一下都立刻跳＋星星 |
| 點第 5 下 | 跳完頭暈 |
| 長按 | 付款魔法（夜間會先醒來，付完再睡回去） |
| 存好一筆支出／收入 | 記帳開心／收入開心 |
| 每 4～8 秒 | 隨機：抖耳朵、晃身、東張西望、晃耳朵、打招呼 |
| 30 秒沒碰手機畫面 | 打瞌睡、睡著；點角色會醒 |

- 預設表情：預算還夠是微笑；剩不到 15% 或超支是普通臉
- 連續記帳 3 天以上，而且預算還夠，角色會一直臉紅
- 魔法、超支、收入這些動畫播放時，點角色不會打斷
- 手機開了「減少動態效果」，只保留眨眼和點擊效果

## 更新步驟

### 1. 先備份（30 秒）
打開主畫面的 Pearly → 設定 → 「下載備份檔」，存到「檔案」App。

### 2. 交給小龍蝦更新網站
照 Claude 給你的小龍蝦指令做。它會把這個資料夾的檔案複製到原本的 `pearly` 資料夾並推上去。

### 3. iPhone 換成新版
等 1～2 分鐘，把主畫面的 Pearly **完全關掉再打開**，必要時開兩次。看到新角色就是新版了。

### 4. 在主畫面的 Pearly 填同步設定
主畫面的 Pearly 和 Safari 的資料是分開的，測試版填過的金鑰**不會**自動帶過來。

1. 主畫面的 Pearly → 設定 → GitHub 自動同步
2. 倉庫：`tiffant931001/pearly-inbox`
3. 金鑰：貼上 GitHub 的金鑰（不記得的話，到 https://github.com/settings/personal-access-tokens 點 Pearly → Regenerate token，再貼一次）
4. 按「儲存並測試連線」，看到「✓ 連線成功」

### 5. 停用測試版的同步
Safari 的測試版也連著同一個倉庫，打開它會把記錄收走。請用 Safari 打開測試版 → 設定 → 「清除同步設定」。小龍蝦指令裡也會把測試網站關掉。

## 捷徑（同步版）

### 捷徑一：LINE Pay（點背面兩下）

用之前做好的「Pearly 同步測試」就可以，改名成 `Pearly 同步`。
設定 → 輔助使用 → 觸控 → 背面輕點：**點兩下**改選「Pearly 同步」，**點三下**改回「無」。

如果要重做，步驟是：
1. **截取螢幕畫面**
2. **從影像中擷取文字**
3. **格式化日期**：目前日期，自訂 `yyyy/MM/dd HH:mm`
4. **文字**：
   ```
   #Pearly
   [擷取的文字]
   記錄時間 [格式化的日期]
   ```
5. **Base64 編碼**：輸入上一步的「文字」，換行選「無」
6. **格式化日期**：目前日期，自訂 `yyyyMMddHHmmss`
7. **取得 URL 的內容**：
   - URL：`https://api.github.com/repos/tiffant931001/pearly-inbox/contents/inbox/p-[第 6 步的日期].txt`
   - 方法 **PUT**；標頭 `Authorization` = `Bearer 你的金鑰`、`Accept` = `application/vnd.github+json`
   - 要求本文 JSON：`message` = `add`、`content` = 第 5 步的結果
8. **顯示通知**：`已送到 Pearly`

**用法**：LINE Pay 付完，LINE 錢包的通知跳出來時點背面兩下（來不及就拉下通知中心再點）。

### 捷徑二：Apple Pay（付款後自動）

打開原本的 Apple Pay 自動化，把「拷貝到剪貼板」換成捷徑一的第 5～8 步（Base64 編碼、格式化日期、取得 URL 的內容、顯示通知）。第 2 步的文字維持原本的：
```
#Pearly
Apple Pay
NT$ [金額]
商店名稱
[商家]
[格式化的日期]
```

> 捷徑裡有金鑰，**不要把捷徑分享給別人**。

### 每次記帳
1. 付款，點背面兩下（Apple Pay 不用做事）
2. 打開 Pearly，新記錄會自己出現在待確認
3. 點粉紅框的分類（或改選別的），完成

舊的「＋貼上」還是可以用。

## 出問題時

- **同步失敗提示一直在**：設定頁按「儲存並測試連線」看錯誤訊息。「金鑰無效或過期」就重新產生金鑰再貼一次。
- **想退回舊版**：請小龍蝦在 `pearly` 資料夾執行 `git revert HEAD` 再 `git push`，然後把 Pearly 完全關掉重開兩次。資料不會消失。
- **角色沒出現、只看到靜態圖**：網路太慢時會先停在靜態圖，載好會自己換成會動的角色。第一次載入後就會存在手機裡。

## 之後更新版本

1. 用新的檔案取代舊的。
2. `sw.js` 第一行附近的版本號加 1（現在是 `pearly-v10`）。
3. 請小龍蝦推上去，iPhone 把 Pearly 完全關掉再打開兩次。

## 記錄經過哪裡

- 截圖在 iPhone 上辨識文字，圖片不會上傳
- 辨識出的文字會暫存在你的私人倉庫 `pearly-inbox`，Pearly 收完就刪掉；倉庫的修改紀錄會留著，只有你看得到
- 簡訊驗證碼會被遮掉，不會存進 Pearly
