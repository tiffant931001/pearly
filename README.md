# Pearly v11 更新說明

v11 是在 v10 上改的。資料 key 沒變（`pearly-app-v1`），**原本的記帳資料、同步設定都會保留**，iPhone 不用重新填金鑰。

## 這版改了什麼

| 項目 | 內容 |
|---|---|
| 長按付款的背景 | 淡粉色像素從中間擴散，拿掉格紋；集氣時約 2.5 秒內一格一格縮回中心，剩角色周圍一小塊後停住，外面變回白色；付款時剩下的粉色像素跟著爆炸散開 |
| 集氣時的角色 | 不再縮那麼小（0.62 倍 → 0.94 倍） |
| 粒子 | 集氣時旁邊的粒子變多；飛進來和散開的範圍更大，散落的粒子和星星也更大 |
| 點角色 | 叮叮聲＋跳＋星星＋耳朵晃，落地後微笑揮手；連點時揮手會被下一下打斷；第 5 下頭暈 |
| 開場揮手 | 叮叮聲＋「哈囉~」。iPhone 在碰過畫面前不讓網頁發聲，所以剛打開那次可能沒聲音 |
| 待機動畫 | 原本 5 種（抖耳朵、晃身、揮手打招呼、東張西望、拍耳朵），改成每 3～5 秒隨機一個；待機的揮手沒有叮叮聲 |
| 打瞌睡 | 30 秒沒點角色就打瞌睡。只有打開 App、點角色、長按付款會重新計時；捲動或點別的地方不算 |
| 角色動畫開關 | 設定 →「角色動畫」開／關。預設開，不管 iPhone 有沒有開「減少動態效果」角色都會動；關掉後角色大多靜止，只會眨眼 |
| 心情文字 | 放大到 15px |
| 跳到 LINE Pay | 維持放開後 1.2 秒 |

## 檔案

- `char10.js` 改名成 `char11.js`（換新名字，手機才不會拿到舊的角色檔）。網站上舊的 `char10.js` 要刪掉。
- `sw.js` 版本號改成 `pearly-v11`
- `snd10.js` 沒有改

## 更新步驟

1. 先備份：主畫面的 Pearly → 設定 →「下載備份檔」。
2. 交給小龍蝦更新網站（照 Claude 給的指令）。
3. 等 1～2 分鐘，把主畫面的 Pearly **完全關掉再打開**，必要時開兩次。點角色有叮叮聲就是新版了。

## 想退回 v10

請小龍蝦在 `pearly` 資料夾執行 `git revert HEAD` 再 `git push`，然後把 Pearly 完全關掉重開兩次。資料不會消失。

## 之後更新版本

1. 用新的檔案取代舊的。
2. `sw.js` 的版本號加 1（現在是 `pearly-v11`）。
3. 請小龍蝦推上去，iPhone 把 Pearly 完全關掉再打開兩次。

## 捷徑、同步、隱私

和 v10 一樣，沒有改。
