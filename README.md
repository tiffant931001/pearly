# Pearly v13 更新說明

v13 是在 v12 上改的。資料 key 沒變（`pearly-app-v1`），**原本的記帳資料、同步設定、金鑰都會保留**。

## 這版改了什麼

| 項目 | 內容 |
|---|---|
| 新的待確認進來（截圖同步） | 留在首頁。待確認區塊從右邊約 120px 滑入並淡入，到位後往左彈 6px；區塊高度 0.4 秒展開，角色跟著往下滑。叮叮叮響一次，「N NEW」從 0 數到總數，卡片邊緣冒出白色四角星（1 筆 4 顆、多筆 7 顆），角色往上看一下。多筆才跳出「收到 N 筆新的付款紀錄」 |
| 原本就有待確認、又進來新的 | 最上面那一筆不變，所以不滑入，只有叮叮叮、數字滾動、星星 |
| 首頁顯示哪一筆 | 改成最舊的一筆（v12 其實是顯示最新的一筆） |
| 選分類 | 只有 tap 按鍵聲，角色不動，不再響叮叮叮 |
| 按確認（還有待確認） | 卡片飛行和 coin 聲照舊，花費格冒 3 顆四角星，0.25 秒後角色「一般開心」：很輕的小叮、蹲下、跳起來、5 顆星、耳朵拍 3 下、一聲啵、落地 |
| 按確認（最後一筆，清空） | coin 後待確認區塊 0.35 秒收合，角色跟著往上滑回原位，接著「特別開心」：蓄力停頓、跳得比一般高、空中停一下、眼睛閃星＋8 顆星、落地，配原本的啵啵啵 |
| 連續確認 | 角色還在播一般／特別開心時，不會被重播打斷 |
| 晚上睡著時清空 | 不叫醒，繼續睡 |
| 關閉角色動畫時 | 一般開心＝靜態角色跳一下；特別開心＝連跳兩下 |
| 減少動態效果 | 新卡片簡單淡入，區塊展開／收合保留，不出現星星 |
| 結帳長按愛心 | 不再縮到完全沒有，停在約 3～4 格的小愛心；縮小的 1.2 秒內有兩組「咚咚」心跳，每拍脹大約 15%，第二組用力一點，配很輕的咚咚聲。放開後和原本一樣 |
| 沒有改的 | 手動貼上的流程、其他地方的啵、付款跳轉 LINE Pay |

「清空」的意思是首頁的「N NEW」變成 0，不包含「需要你決定」的重複、原文紀錄。

## 檔案

- `char12.js` 改名成 `char13.js`（新名字，手機才不會拿到舊的角色檔）。網站上舊的 `char12.js` 要刪掉。
- `index.html` 重新產生
- `sw.js` 版本號改成 `pearly-v13`
- `snd10.js`、`manifest.webmanifest`、`icons/` 沒有改

## 更新步驟

1. 先備份：主畫面的 Pearly → 設定 →「下載備份檔」。
2. 交給小龍蝦更新網站：用這個資料夾的檔案取代 `pearly` 資料夾裡的同名檔案，刪掉 `char12.js`，然後 commit、push。
3. 等 1～2 分鐘，把主畫面的 Pearly **完全關掉再打開**，必要時開兩次。設定頁「角色動畫」下面的狀態小字還在、選分類時不再響叮叮叮，就是新版了。

## 想退回 v12

請小龍蝦在 `pearly` 資料夾執行 `git revert HEAD` 再 `git push`，然後把 Pearly 完全關掉重開兩次。資料不會消失。
