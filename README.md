# Pearly v12 更新說明

v12 是在 v11 上改的。資料 key 沒變（`pearly-app-v1`），**原本的記帳資料、同步設定都會保留**，iPhone 不用重新填金鑰。

## 這版改了什麼

| 項目 | 內容 |
|---|---|
| 長按付款的背景 | 按下：圓形衝擊波推出去，0.5 秒，深粉色邊。集氣：粉色變成愛心形狀往中心縮，1.2 秒縮到完全沒有，只有一圈淡邊。放開：愛心帶深粉色邊擴張，邊緣有少量飛散的小像素，0.42 秒。跳到 LINE Pay 維持 1.2 秒 |
| 待機動畫 | 改成每 4～7 秒一個。加了保護：動作出錯也會繼續排下一個；醒著時超過 12 秒完全沒動，會自動重置並馬上放一個 |
| 角色狀態小字 | 設定 →「角色動畫」下面顯示：待機中／忙碌／睡著／長按中、待機動作次數、上一個是幾秒前、自動修復次數 |
| 關閉角色動畫 | 不載入角色檔，換成靜態角色：輕輕漂浮，點一下會跳。付款背景動畫和開著時一樣。切換時畫面會重新載入 |
| 夜晚模式（新） | 設定 →「夜晚模式」：自動（21:00～06:00，預設）、自訂時間（可以跨午夜）、關閉。關閉時晚上不會自動睡覺，30 秒沒點角色還是會打瞌睡 |
| 「其他」分類（新） | 第 10 個大項。待確認頁的九宮格下面多一條全寬的「其他」。自動分類不會學「其他」。細項：禮物、捐款、手續費、雜支 |
| 明細搜尋（新） | 明細頁最上面的搜尋欄。搜所有月份已確認的紀錄，可以搜店名、備註、細項、分類和金額，最上面顯示共幾筆、總支出 |
| 月份比較（新） | 圖表頁加「比上月」：這個月是跟上個月同一段日期比（例如都是 1～23 號），過去的月份是整月比整月。分類清單每列有「↑／↓ 多少」。這個月沒支出的大類收起來 |
| 手動記帳 | 「日期」可以點來改；拿掉沒有作用的「[PAY] 手動」格 |
| 待確認頁 | 拿掉重複的「待確認」標題 |
| 可讀性 | 要讀、要填、要按的字放大到至少 11px，輸入欄標籤改成 13px；灰字、刪除鍵、「＋細項」、材料費色塊加深到對比 4.5:1 以上；小按鈕的點擊範圍加大。`[MOOD]` 這類裝飾標籤維持原樣 |

## 檔案

- `char11.js` 改名成 `char12.js`（換新名字，手機才不會拿到舊的角色檔）。網站上舊的 `char11.js` 要刪掉。
- `index.html` 重新產生
- `sw.js` 版本號改成 `pearly-v12`
- `snd10.js`、`manifest.webmanifest`、`icons/` 沒有改

## 更新步驟

1. 先備份：主畫面的 Pearly → 設定 →「下載備份檔」。
2. 交給小龍蝦更新網站：用這個資料夾的檔案取代 `pearly` 資料夾裡的同名檔案，刪掉 `char11.js`，然後 commit、push。
3. 等 1～2 分鐘，把主畫面的 Pearly **完全關掉再打開**，必要時開兩次。設定頁出現「夜晚模式」就是新版了。

## 想退回 v11

請小龍蝦在 `pearly` 資料夾執行 `git revert HEAD` 再 `git push`，然後把 Pearly 完全關掉重開兩次。資料不會消失。

## 之後更新版本

1. 用新的檔案取代舊的。
2. `sw.js` 的版本號加 1（現在是 `pearly-v12`）。
3. 請小龍蝦推上去，iPhone 把 Pearly 完全關掉再打開兩次。

## 捷徑、同步、隱私

和 v11 一樣，沒有改。
